# Scrubbed source JSON archive

These are derived public copies. The existing cards/ source files are unchanged.

- objects/<sha256>.json.gz: gzip-compressed scrubbed JSON. The filename is the SHA-256 of the decompressed UTF-8 bytes.
- cards/<CardID>.json: playlist/store source references for one card, retaining distinct content versions.

Personal contact/account fields and protected playlist links are withheld. Known MYO/Yoto Space sharing links remain public. Originals and restore evidence are stored separately in private Cloudflare R2.

All 22,326 public objects passed checksum, sensitive-field and protected-link checks before publication.
